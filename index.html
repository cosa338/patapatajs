patapata.js とは

JA/EN

数字や文字を「パタパタ」アニメーションで表示する Web Components (Custom Elements)ライブラリです。
時計・残り時間・カウントダウン/ストップウォッチ・テキスト切り替えなどを、HTMLだけで組み込めます。
各種オプションはデモで確認してください。

                    - interval は常に 16ms 固定 (指定しても無効)です。

                    

                    - S/SS/SSS のパネルは duration=400 固定、それ以外は指定した duration で動きます。

                    

                    - formatトークン YYYY=西暦(4桁) / YY=西暦(2桁) / MM=月(01-12) / DD=日(01-31) / HH=時(00-23) /
                    HH12=時(01-12) / ampm=AM/PM / ampm_jp=午前/午後 / mm=分(00-59) / ss=秒(00-59) / S=100ms(0-9) /
                    SS=1/100秒(00-99) / SSS=ミリ秒(000-999) / ddd=曜日(SUN..SAT) / ddd_jp=曜日(日..土)

                    

                    - diff に日時を指定すると、現在時刻ではなく「指定日時 - 現在時刻」の残り時間を表示します。

                    

                    - diff時のformatトークン DDD=残り日数(全桁) / HHH=残り時間(全桁) / mmm=残り分(全桁) / sss=残り秒(全桁) / HH=時(00-23) /
                    mm=分(00-59) / ss=秒(00-59) / S=100ms(0-9) / SS=1/100秒(00-99) / SSS=ミリ秒(000-999) ※diff がマイナスの場合は '-'
                    が付きます
                

                

                    - interval は常に 16ms 固定 (指定しても無効)です。

                    

                    - S/SS/SSS のパネルは duration=400 固定、それ以外は指定した duration で動きます。

                    

                    - sec を指定するとカウントダウンになり、0で停止します。

                    

                    - click を指定するとクリックで Start → Stop → Rest の動作になります。

                    

                    - formatトークン HHH=合計時(全桁) / mmm=合計分(全桁) / sss=合計秒(全桁) / mm=分(00-59) / ss=秒(00-59) /
                    S=100ms(0-9) / SS=1/100秒(00-99) / SSS=ミリ秒(000-999)
