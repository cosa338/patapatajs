patapata.js

patapata.js とは

数字や文字を「パタパタ」アニメーションで表示する Web Components (Custom Elements) ライブラリです。依存ライブラリのない 1 ファイルのスクリプトで動作します。

時計、指定日時までの残り時間、カウントダウン / ストップウォッチ、テキストの切り替えなど、さまざまな表示を HTML を書くだけでページに組み込めます。

このページはデモ兼ドキュメントです。プリセットギャラリーで実際の動きを確かめて、Playground で好みに調整すれば、貼り付けてそのまま使える HTML を生成できます。

Setup

スクリプトを 1 つ読み込んで、要素を置くだけ。ビルドも npm も不要です。


            

        


        
        

            

                
プリセットギャラリー

                
要素ごとのプリセット一覧。クリックで Playground に読み込んで、そのまま調整できます。
